# LOTUS FIN 云端部署综合指南 (LINUX 云服务器端到端实操)

> **核心系统：** Lotus Fin — 基于 Frappe/ERPNext 与确定性金融 AI 核心的中小企业财务管理平台  
> **目标运行环境：** Linux 云服务器 / VPS (Ubuntu 22.04 LTS / Debian 12)  
> **最低硬件要求：** 2 vCPU — 4 GB 内存 (推荐 8 GB) — 40 GB SSD  
> **架构模式：** 单机独立部署 (宿主机 Nginx 反向代理 + React 静态分发 + 9 个 Frappe/ERPNext Docker 微服务容器)

## 常用运维维护命令速查表

在服务器的 `~/lotus-fin` 根目录下执行：

```bash
# 启动 9 个容器组成的微服务集群
./run.sh up

# 将本地最新代码同步进容器并执行数据库 Schema 迁移
./run.sh sync

# 灌入仿真财务演示数据集 (包含发票、应收账款与总账凭证)
./run.sh demo

# 运行 What-If 复合场景财务压力测算 (测算 9 项核心 KPI)
./run.sh simulate

# 执行自动化财务核心用例单元测试套件
./run.sh test lotus_fin.tests.test_financial_health

# 查看当前所有容器的实时物理内存与 CPU 负载
docker stats --no-stream

# 清理无用的临时构建缓存与悬空 Docker 镜像
docker system prune -f
```
