# AI-F005 — 中小企业信贷产品撮合引擎 (AI005)

> **功能代号：** `AI005` / `AI-F005`  
> **研发状态：** 已完成实现并通过验证  
> **计算类别：** 确定性银行准入评分 + 商业金融产品目录撮合  
> **对应源码模块：** `lotus_fin.modules.f005_financing`  
> **核心不变量：** 仅限模拟咨询沙箱、确定性准入逻辑、零 PII 敏感数据  

---

## 1. 业务痛点与功能概述
破解中小企业融资难、信息不对称的困局。当系统监测到企业未来现金缺口时，引擎自动抓取企业实时总账与现金流表现（如 DSCR、营业净收入、优质应收账款抵押物），并与商业银行的信贷产品准入目录进行确定性匹配。

### 覆盖的 4 类主流企业信贷模型
- **循环流动资金贷款 (Revolving Line):** 基于企业月均稳定流水匹配的随借随还短期流动性额度。
- **发票质押与保理融资 (Invoice Discounting):** 基于已入账、未结清且无争议的优质应收账款快速变现。
- **中长期设备与资本性支出贷款 (Capex Term Loan):** 配合企业固定资产购置的多期等额分期贷款。
- **商户流水贷 (Merchant Cash Advance):** 依据高频收单流水核定的小微短期周转额度。

---

## 2. 准入评估核心维度
- **偿债倍数 (DSCR):** 计算 `(EBITDA - 税费) / 总债务本息支出`，比对银行硬性底线（主流银行通常要求 >= 1.25x，普惠金融科技机构要求 >= 1.10x）。
- **速动比率与月均流水:** 评估企业的快速变现储备和月度经营稳定性。

---

## 3. 架构不变量与安全控制
1. **确定性准入规则：** 评分标准与准入状态完全通过确定性逻辑门测算，大语言模型无权审批或篡改准入结论。
2. **仅限决策咨询沙箱：** 引擎仅提供撮合建议，严禁直接对接放款或触发资金下发操作。
3. **敏感信息最小化：** 发送给 AI 顾问用于生成通俗建议的内容中已剔除全部企业隐私信息与客户名录。
