## 1. 业务痛点与功能概述
中小微企业往往由于缺乏专职风控团队，无法在现金流陷入枯竭之前察觉到营运风险。AI003 实时扫描 ERP 会计总账及往来账龄，对潜在的资金链紧张和坏账风险提前进行多维度穿透预警。

### 核心风险信号捕捉
- **`AP_DUE_CLUSTER` (应付账款过度聚集):** 监测未来极窄时间窗口内是否有密集供应商付款扎堆（例如：月度支出的 40% 以上集中在连续 5 天内）。
- **`AR_OVERDUE_SPIKE` (逾期账款激增与账龄恶化):** 监控长期逾期应收账款（特别是超期 60 天以上账款）的异动与恶化趋势。
- **`LIQUIDITY_DRAIN` (安全现金跑道告急):** 当企业实际库存现金仅能维持不足 15 天日常经营时触发高危预警。
- **`REVENUE_VOLATILITY` (主营业务收入异常收缩):** 识别环比或同比跌幅超过容忍阈值的剧烈收入波动。

## 2. 架构不变量与安全控制
1. **确定性阈值触发机制：** 风险信号的触发完全依赖确定的数学公式与业务阈值判定，大语言模型无权捏造或隐瞒风险信号。
2. **多租户权限校验：** 仅当用户具备该租户公司的有效财务查看权时才允许执行账目扫描。
3. **审计追溯与证据留痕：** 每个被触发的风险信号均明确关联底层单据编号与金额事实，供财务操作人员随时核实。
