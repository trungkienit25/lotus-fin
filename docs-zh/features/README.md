# 金融 AI 核心引擎矩阵 (F001 – F007)

欢迎查阅 **Lotus Fin 金融 AI 核心引擎** 文档目录。Lotus Fin 深度研发并落地了 7 大确定性、全链路可追溯的计算引擎，专为中小微企业 (SME) 提供全方位的自动化财务决策支持。

---

## 🏛️ 核心架构不变量与安全守则

在全部 7 大功能模块中，Lotus Fin 严格践行零幻觉与企业级安全准则：

1. **确定性计算不变量 (Zero-AI Calculation Invariant):** 严禁大语言模型 (LLM) 进行财务数值加减乘除、总账凭证汇总或财务指标推算。所有数值必须且只能由经过严格审计的 Python 原生计算引擎使用高精度 `Decimal` 运算生成。
2. **事实锚定与展现网关 (Grounding & Presentation Gate):** 大语言模型仅负责将计算引擎输出的强类型财务事实，翻译并总结为符合管理层视角的自然语言分析摘要。
3. **多租户安全边界 (Multi-Tenant Boundary):** 每个引擎强制校验当前调用者的所属公司上下文 (`company`)，越权请求将触发不可透传的 `CompanyAccessError` 异常阻断。
4. **Level 4 人机协同双阶段提交 (Human-in-the-Loop):** 涉及对账函派发、催收通知发送等外部操作，智能体仅生成待确认卡片，必须由人工操作员在界面显式核验并点击“确认”后方可触发实际发送。
