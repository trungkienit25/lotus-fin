# AI-F004 — 多变量 WHAT-IF 财务压力模拟器 (AI004)

> **功能代号：** `AI004` / `AI-F004`  
> **研发状态：** 已完成实现并附带权威测试数据验证  
> **计算类别：** 纯内存确定性压力模拟 + 事实锚定的大模型归纳解读  
> **对应源码模块：** `lotus_fin.modules.f004_what_if`  
> **核心不变量：** 零数据库写入、高精度 `Decimal` 运算、强类型声明 `data_mode = "simulation"`  

---

## 1. 业务痛点与功能概述
支持企业经营层和财务总监在纯内存环境中模拟复杂的宏观或经营冲击，在 30 至 90 天规划周期内定量推演 9 项核心财务指标的动态变化。

### 支持的 5 大复合压力修饰因子
1. **营收波动冲击 (Sales Shock):** 模拟主营收入按百分比上升或下滑（如：营收收缩 `-20%`）。
2. **客户回款拖延 (Collection Delay):** 模拟主要应收客户付款账期普遍拖延（如：平均回款延期 `+15 天`）。
3. **供应商账期展期 (Payable Extension):** 模拟与上游谈判争取到的付款账期拉长（如：应付推迟 `+30 天`）。
4. **突发经营支出激增 (Expense Surge):** 模拟设备抢修、原料价格暴涨或临时薪资福利支出。
5. **外部流动性注入 (Financing Injection):** 模拟特定日期获得外部信贷注资或股东增资。

---

## 2. 9 大 KPI 联动压力测算矩阵
模拟器输出基线与模拟结果的精确对比差值 (Delta)：
- 期初现金余额、期末现金净结余、最低现金水位点、首次资金穿底日期、现金安全跑道天数、累计总流入差值、累计总流出差值、资金缺口状态变动以及营运资金净变动。

---

## 3. 架构不变量与安全控制
1. **`INV-SIM-01` (零数据库变更):** 压力模拟完全在易失性内存中执行，严禁向总账凭证或发票表写入任何变更。
2. **`INV-SIM-02` (数据模拟标签印章):** 所有模拟 DTO、API 回包与前端卡片均带有 `data_mode = "simulation"` 标签。
3. **`INV-SIM-03` (确定性高精度计算):** 全部数值运算基于 Python `Decimal`，杜绝浮点精度偏差。
4. **多租户权限校验:** 读取基准现金流事件前必须通过企业租户权限验证。
