## 1. 业务痛点与功能概述
现金流断裂是导致中小企业陷入困境的最主要因素。与传统的宏观统计学估算不同，AI002 依托企业 ERP 系统中真实录入的销售发票、采购账单和贷款合同排期，按日精确构建未来 30 天的刚性流动性全景图。

### 核心功能与推演指标
- **30 天逐日流动性曲线：** 按日精确推演未来 30 天内每个自然日的预期流入、流出及每日收盘现金净结余。
- **合同真实排期对齐：** 仅提取已审核提交业务凭证 (`Sales Invoice`、`Purchase Invoice`、`Payment Schedule`) 的约定支付日期，拒绝任何数值插值。
- **资金最低谷与缺口预警：** 自动精确定位未来流动性最薄弱日期，并在可能出现资金穿底时提前发出预警。
- **安全经营资金跑道：** 测算在当前支出速度下企业库存现金可维持的有效经营天数。

---

## 2. 架构不变量与安全控制
1. **合同排期事实依据：** 所有流动性数字均严格锚定真实的 ERP 业务单据。
2. **零大模型幻觉：** 严禁大语言模型预测或猜测未来收支金额，模型仅用于对算法排期表进行自然语言归纳解读。
3. **多租户数据防护：** 现金流报表按租户公司强隔离，防止企业间账务交叉访问。
4. **单据交叉去重机制：** 在汇总发票分期与已录入付款凭证时，执行基于凭证唯一标识的幂等去重，防止资金重叠重复计算。
