## 1. 业务痛点与功能概述
中小微企业财务负责人通常面临总账、试算平衡表、应收账款和应付账款明细分散的痛点。AI001 负责将 ERPNext 底层总账凭证自动转化为透明、可穿透追溯的财务健康仪表盘，无需人工进行繁琐的电子表格合并。

### 核心计算指标
- **营业净收入与毛利：** 严格基于利润表主营业务收入与主营业务成本 (COGS) 计算。
- **综合毛利率：** `(主营业务收入 - 主营业务成本) / 主营业务收入`，采用原生高精度 `Decimal` 运算。
- **偿债能力倍数 (DSCR)：** 计算经营活动现金流对即将到期的债务本息支出的覆盖比率。
- **净营运资金与速动比率：** 评估企业随时变现以偿付短期经营负债的能力。
- **逾期应收/应付账款余额：** 汇总全部逾期往来账项并自动按照账龄区间进行分层。

## 2. 架构不变量与安全控制
1. **零 AI 计算不变量：** 严禁大语言模型计算或推测财务数字，全部核心指标均由经过审计的 Python 确定性服务汇总。
2. **确定性状态表达：** 当账目未入账或对应期间凭证缺失时，返回显式的 `UNAVAILABLE` 或 `PARTIAL` 状态，严禁大模型捏造虚假为零的数据。
3. **多租户严格隔离：** 每次报表提取均执行强制公司访问校验 (`company`)，未授权请求立即抛出 `CompanyAccessError` 异常阻断。
4. **零 PII 敏感信息脱敏：** 传递给大模型用于生成总结的载荷中仅包含聚合后的比率与数值指标，已自动剥离客户名录、银行账户等隐私信息。
