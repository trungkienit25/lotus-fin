## 1. 业务痛点与功能概述
还本付息通常是企业最刚性的现金流流出。浮动利率贷款容易受宏观货币政策紧缩的影响。当央行基准利率上调时，企业偿债倍数面临恶化风险。AI006 提供高精度的还款排期测算，并支持模拟利率上浮 (+100 至 +300 基点) 对企业现金流的冲击。

### 核心计算模型与情景模拟
- **等额本息还款法 (PMT 年金模型):** 每月偿还相同金额（本金 + 利息）：
  $$PMT = P \times \frac{r(1+r)^n}{(1+r)^n - 1}$$
- **等额本金还款法 (递减模型):** 每月偿还固定本金，利息随未还本金减少逐月递减。
- **宽限期模拟:** 支持在项目建设期仅付息不还本的宽限期设置。
- **基点加息压力测试:** 测算利率上调 `+100 bps`、`+200 bps` 或 `+300 bps` 带来的累计利息新增开销及月度现金流挤压。

---

## 2. 架构不变量与安全控制
1. **高精度 Decimal 运算：** 每期应还本息与余额计算完全遵循 Python `Decimal`，杜绝浮点累计误差。
2. **零大模型数值幻觉：** 还款计划表全部由确定性数学算法生成，模型仅负责将其转化为给管理层的通俗中文摘要。
3. **咨询模式隔离：** 还款测算结果仅供财务决策参考，严禁自动向 ERP 录入付款凭单。
