# AI-F007 — 催收回款协助与对账凭据派发 (AI007)

> **功能代号：** `AI007` / `AI-F007`  
> **研发状态：** 已完成实现并通过验证  
> **计算类别：** 确定性发票对账检索 + Level 4 人机协同双阶段提交  
> **对应源码模块：** `lotus_fin.modules.f007_copilot`  
> **核心不变量：** 必须人工确认发函、发票事实强锚定、模板防注入安全清洗  

---

## 1. 业务痛点与功能概述
应收账款回收直接关乎企业的经营命脉。但传统催款流程需要人工繁琐翻查逾期发票、逐笔对账并手写催款邮件。AI007 扮演财务催收助理角色，快速扫描未清发票，一键生成合规的催收对账单，并通过 **Level 4 双阶段确认** 机制安全下发通知。

### 核心功能链路
- **发票快速检索与账龄分组:** 按照客户、付款状态（逾期、未结清）及逾期天数（1-30天、31-60天、61-90天、90天+）快速归类。
- **动态合规催收函生成:** 自动填充发票号、开票金额、未付余额、约定到期日及企业官方银行收款账户。
- **Level 4 双阶段确认 (人机协同):** 任何外部发函操作必须先在前端展示待确认预览卡片，由财务人员人工复核无误并点击“确认发送”后，后端才调用 `frappe.sendmail` 执行实际派发。

---

## 2. 架构不变量与安全控制
1. **`INV-COP-01` (严禁自主对外发函):** 智能体严禁自主决定向客户发送催款邮件，必须保留人工最终控制权。
2. **`INV-COP-02` (发票事实强锚定):** 催收函中的发票号、欠款金额必须直接源于数据库已审核单据，严禁模型自行生成账目。
3. **`INV-COP-03` (模板清洗与防篡改):** 对邮件正文及客户备注严格执行 HTML 实体转义，严防邮件头伪造与 XSS 跨站脚本攻击。
