## 1. 金融大模型面临的威胁态势与攻击面

在企业级财务核算系统中引入大语言模型 (LLM)，会引入一系列直接威胁会计账目完整性的系统级安全脆弱点：

1. **财务数值幻觉与误导 (OWASP LLM09):** 概率型语言模型容易编造看似合理的虚假营业额、算错复利与还款利息，或凭空捏造银行现金结余。
2. **Prompt 注入与系统设定篡改 (OWASP LLM01):** 攻击者将恶意提示词隐藏在发票备注或客户留言中，诱导大模型突破业务规则与权限边界。
3. **过度授权与自主操作风险 (OWASP LLM06):** 智能体未经人类复核批准，私自执行记账、下发付款任务或对外发送具有法律效力的对账催款函。
4. **机密账务泄露与上下文越权 (OWASP LLM02):** 未经脱敏直接将企业全量总账凭证或内部数据结构发送给第三方模型供应商。
5. **无界计算资源耗尽 (OWASP LLM10):** 失控的 ReAct 智能体死循环导致单次请求无休止调用，耗尽企业 API Token 额度。

Lotus Fin 通过 **纵深防御策略** 以及 **自然语言推理与确定性计算引擎的物理彻底隔离**，彻底攻克上述威胁：

## 2. 深度 AI 安全控制与实施蓝图

### 2.1. 严格受控的工具白名单与有界执行预算

#### 痛点场景
在间接 Prompt 注入攻击中，恶意发票文本会指令大模型调用未授权的内部管理函数，或诱导模型进入死循环耗尽 API 额度。

#### 解决方案
1. **闭门工具白名单：** 大模型仅能感知并调用系统中明确注册的 7 大金融分析工具。任何不在白名单内的工具调用均被调度器在执行前阻断。
2. **硬性执行预算：**
   * **迭代次数上限：** 单次问答严格限制在 **4 次迭代** 以内。
   * **工具调用上限：** 单次会话最多执行 **6 次工具调用**。
   * **外部熔断机制：** 30 秒内连续 5 次发生外部提供商调用失败，系统立即自动切断外部请求，保护系统可用性。

---

### 2.2. 确定性金融计算不变量与零 AI 数学计算 (INV-03)

#### 痛点场景
大语言模型本质上是概率型词元预测机，在计算复利息差、毛利率比率及每日现金余额时极易发生算术逻辑错误。

#### 解决方案
1. **零 AI 计算不变量：** 严禁大模型计算任何财务账目。全部金融指标均由原生 Python 高精度 `Decimal` 引擎运算：
   * **主营收入与毛利：** 直接从已审核的总账分录 (`docstatus = 1`) 聚合。
   * **30 天现金流走势：** 严格基于发票约定的支付排期汇总。
   * **贷款分期计划：** 严格按标准 PMT 年金精算公式求解：
     $$\text{PMT} = P \times \frac{r(1+r)^n}{(1+r)^n - 1}$$
   * **利率冲击测算：** 通过直接在年利率中增加基点 (+100, +200, +300 bps) 推演增量利息。
2. **绝对数值容差核验：** 大模型生成的归纳文本若提及任何具体数值，必须与底层计算事实进行绝对比对；一旦偏差超过 $\pm 0.05$，该段分析即被自动丢弃，前端改为直接呈现标准数据表格。

---

### 2.3. 展现网关自动化净化与数据脱敏

#### 痛点场景
大模型直接返回的文本经常夹带底层数据库字段名（如 `has_constituent_deficit`）或内部测试标签（如 `STRICT_BASELINE_V1`），影响阅读且暴露底层数据架构。

#### 解决方案
Lotus Fin 部署了自动化展现网关净化器 (`sanitize_executive_reply`)：
* 自动拦截大模型生成的原始输出。
* 剔除所有底层布尔标志（如 `constituent_deficit: false`）与内部标签。
* 移除空 JSON 括号与技术排错调试代码，确保呈现给管理层的文本专业、干净。

---

### 2.4. Level 4 人机协同双阶段提交治理 (Two-Phase Commit)

#### 痛点场景
若赋予 AI 智能体自主写账或对外发函的特权，一旦模型理解偏差，将引发不可逆的法律与经济纠纷。

#### 解决方案：4 级自治治理体系
* **Tier 0 (只读分析):** 检索财务健康数据与账龄分析。允许对已登录用户自主执行。
* **Tier 1 (模拟推演):** 模拟 What-If 压力测试与本地账单预览。允许自主执行。
* **Tier 2 (业务变更):** 创建待办任务、暂存催收函草稿。**强制要求人工介入与双阶段确认。**
* **Tier 3 (高危资金操作):** 银企直联转账、修改收款账号。**永久性阻断调用 (`R4=DENY, R5=DENY`)。**
