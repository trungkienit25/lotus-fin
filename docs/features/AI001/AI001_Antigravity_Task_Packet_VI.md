# Task Packet — Antigravity / AI001

**Feature:** AI001 = **AI-F001 Financial Health Analyst** theo `LotusFin_AI_Features_Codebase_Aligned_v1.md` §5; primary UC003, supporting UC009/UC006. Đọc [Feature Freeze](AI001_Feature_Freeze_VI.md) làm contract P0; `AI-001` trong Security SSOT là test ID khác. **Hiện trạng:** `NOT_READY_TO_CODE`; chưa viết code cho đến khi DoR và 4 gate được chứng minh.

## Nhiệm vụ theo thứ tự

1. **Runtime + dataset inventory:** ghi Frappe/ERPNext version, site/company/role topology; kiểm **bản ghi sẵn có** và quyền sử dụng trên target/test/demo company. Xác minh P&L, Balance Sheet/Trial Balance/GL/Cash Flow, AR/AP, voucher/payment sources cho revenue, expense/COGS, cash/proxy, AR total/overdue, AP total/near-term. Capture schema, period/currency/Finance Book/as-of, permissions, empty-vs-error ở **ít nhất 2 company** có cấu hình/dữ liệu khác nhau; đánh dấu fact `VERIFIED/NOT_VERIFIED/NOT_AVAILABLE`.
2. **Chốt provenance + contract:** ưu tiên ERPNext records có sẵn, đã xác minh và được phép dùng. Nếu test/demo thiếu ca cần thiết, định nghĩa fixture synthetic từ giao dịch ERPNext hợp lệ và source/schema chính thức; ghi manifest, seed, license/source_refs, transformation, invariant và gold độc lập. Không dùng Olist/WBES/SEC như sổ cái một company. Đối chiếu KPI candidates với nguồn thật; chốt schema/bounds/snapshot/EvidenceRef. Chọn **model qua API** với version, region/retention, secret, timeout/rate/cost budget, data minimization và eval rubric; không đưa local model vào deployment P0. Cập nhật Feature Freeze và ghi nhận sign-off bốn gate. Thiếu nguồn production thì báo blocker; không dùng synthetic để giả vờ production đủ dữ liệu.
3. **Thiết kế preprocessing trước code:** theo §2.4 Feature Freeze, vẽ mapping `report/DocType → field chuẩn → FinancialSnapshot → KPI`; chốt schema/empty/error, period/as-of, timezone, decimal/currency/sign, chart-of-accounts mapping, payment/credit allocation, overdue AR, near-term AP window, dedup, data quality rules, reconciliation/tolerance, trust-state và lineage/version. Ghi rõ rule reject/partial cho dữ liệu thiếu/sai; model API chỉ nhận payload KPI/evidence tối thiểu, không report thô. Tạo fixture/gold cho từng rule và source status. **Output:** data mapping table + transformation spec + validation/reconciliation checklist + fixture manifest; không bắt đầu implementation khi các rule material chưa được xác minh.
4. **Chỉ sau READY:** triển khai adapter có company authorization và preprocessing `extract → validate → normalize → derive → reconcile/trust → snapshot/evidence`, rồi deterministic KPI, grounded LLM explanation, typed failure và observability đúng Feature Freeze. Model lỗi thì trả KPI hợp lệ với explanation unavailable; đây chưa phải Done của Analyst. Không mở general Copilot chat/RAG/forecast/bank write trong packet này.
5. **Verify:** unit numeric gold độc lập; adapter contract với schema thật; kiểm preprocessing trên ca duplicate, null, credit/partial payment, kỳ/as-of, đa currency, empty vs source error và reconciliation fail; integration trên ERPNext test site 2 company/2 users (đủ/thiếu dữ liệu, allow/deny); mock model API 200/timeout/429/5xx/bad schema và staging smoke test provider thật; E2E đối chiếu báo cáo ERPNext, explanation fidelity, XSS/prompt injection, audit/trace/cost. Báo kết quả từng gate, evidence, hạn chế và trạng thái `IMPLEMENTED/PARTIAL/NOT_VERIFIED`.

**Deliverables:** runtime facts + evidence; data mapping/transformation spec, data quality + reconciliation checklist, fixture manifest; Feature Freeze đã cập nhật/được duyệt; implementation và test evidence **chỉ khi READY**; báo cáo acceptance ngắn. Không báo hoàn thành nếu KPI sai, có cross-company leak, lỗi nguồn biến thành zero, hoặc thiếu bằng chứng cho claim.
